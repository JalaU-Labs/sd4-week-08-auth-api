# Release v0.1.0

## Features
- Initial public authentication API with register, login, me, and logout endpoints.
- In-memory user and session stores with configurable TTL.
- Swagger UI and OpenAPI schema at /docs and /openapi.json.
- Multi-stage Docker image running FastAPI, Casdoor, and Caddy in a single container.
- Caddy reverse proxy routing /casdoor/* to Casdoor and everything else to FastAPI.
- CI/CD pipelines for GitLab CI (Buildah) and GitHub Actions with dual-registry publish (GHCR and GitLab Registry).
- Render Blueprint (render.yaml) for image-backed deployment.
- Casdoor admin password injection from environment at startup.
