# Release v0.1.2

## Features
- **Casdoor SSO Integration**: Users can now authenticate via Casdoor OIDC. The API handles the authorization code flow, validates the ID token against Casdoor's JWKS, and issues a local API bearer token.
- **JIT Provisioning**: Users authenticating via Casdoor for the first time are automatically provisioned in the in-memory UserStore.
- **Documentation**: Comprehensive updates to README.md, including local development, production deployment, and API contract details.
- **Changelog**: Added CHANGELOG.md to track project history.

## Bug Fixes
- (Inherited from v0.1.1) Fixed Casdoor subpath deployment and static asset loading.
