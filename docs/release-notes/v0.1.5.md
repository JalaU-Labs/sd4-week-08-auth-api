# Release v0.1.5

## Fixed
- Encode the OAuth `state` value when starting Casdoor authorization and decode it before validating the callback.
- Forward the Casdoor OIDC client ID, client secret, issuer, and redirect URI from the local environment into the production Compose container.

## Changed
- Expand OpenAPI metadata, endpoint descriptions, response documentation, and request and response examples.
- Document Swagger UI authorization and troubleshooting for the Casdoor redirect flow.

## Deployment note
- `CASDOOR_CLIENT_SECRET` remains a Render-managed secret and must be set in the Render service environment. The Blueprint intentionally uses `sync: false`.
